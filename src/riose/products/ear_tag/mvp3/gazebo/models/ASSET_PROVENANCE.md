# MVP3 visual asset provenance

## Procedural cow, soil, grass, and PBR maps

- **Source:** `scripts/build_mvp3_visual_assets.py` in this repository.
- **Author:** RIOSE project contributors; deterministic meshes and pixel maps are generated by the checked-in script.
- **License:** No standalone SPDX license file was present in this checkout. No third-party mesh, image, or texture was imported; the generated project assets do not claim an external asset license.
- **Reference:** local script above; no external URL/source reference applies.
- **Modifications:** the bovine lofts, ears, hoof/leg proxies, sparse coat pattern, bounded paddock grass mesh, ground material maps, and roughness maps were authored procedurally for Gazebo OGRE2. Geometry is stylized and is not breed-specific.

## RIOSE enclosure

- **Source:** `hardware/mechanical/model.py` and `results/mvp2/mechanical/geometry.json`; generated at `gazebo/models/riose_ear_tag/meshes/ear_tag_assumed.stl`.
- **Author:** RIOSE mechanical project contributors; deterministic export by `scripts/build_mvp3_visual_assets.py` using CadQuery.
- **License:** no standalone project license was found in this checkout; rights remain unspecified. No external enclosure asset was used.
- **Reference:** local MVP2 mechanical source and geometry report above.
- **Modifications:** MVP2 exterior shell regenerated for Gazebo. The STL has no UV coordinates, so Gazebo applies the enclosure's cool-slate PBR base color and scalar roughness; generated polymer texture maps are not applied to this STL. Geometry, mass properties, pivot placement, and attachment parameters retain `ASSUMED` provenance where project source lacks validated measurements.
