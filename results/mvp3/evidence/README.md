# MVP3 evidence index

All saved runs are `SIMULATED`; configured masses, root drive, attachment
properties, and sensor assumptions are `ASSUMED` unless an artifact states
otherwise. No file in this directory contains physical cattle measurements.

- `standing/`, `walking/`, `walking_fast_headless/`, `running/`,
  `head_shake/`, and `attachment_variation/` contain per-run summaries, normalized IMU
  CSV/RESD, and synchronized recording JSONL. The walking, running,
  head-shake, and attachment-variation recordings include world-frame linear
  and angular kinematics derived by finite differences from the timestamped
  Gazebo poses; these are derived values, not separate sensor measurements.
  The original `walking/` bundle also contains Renode logs for sample-register
  readback, boot TX, and the historical test-only DRDY/classifier/TX case. Its `sx1262_tx_trace.json`
  preserves the two completed logical TX payloads and their Renode virtual-clock
  start/done times. `firmware_trace.jsonl` converts only captured packet
  and TX fields for the logical anchor and assumed-load MVP2 power adapters;
  the anchor accepted two logical events and the power result covers the TX
  intervals plus idle baseline only. `walking/` is the paced headless capture
  with a 10/11 gate; `walking_fast_headless/` preserves the earlier accelerated capture
  whose pose join exceeded the validation tolerance.
- `walking_wake_tx/` preserves a separate replay of the same paced Gazebo walk
  through the configured LIS2DW12 WU route. A first-order high-pass comparator
  approximation generated `WU_SRC=0x0C`; firmware woke from `SLEEP`, classified
  `ALERT`, completed a CRC-valid TX, and returned to `SLEEP` after its RX
  window. Its report passes 11/11 digital gate
  checks. `firmware_replay.json` declares the offline affine clock mapping and
  recomputed TX-to-IMU sample alignment (0.231 ms error). This is not live
  lockstep or silicon filter validation. Its RF and power outputs remain
  simulated/assumed as noted in the per-run report.
- `mass_sweep/mass_sweep_summary.csv` contains the 20–40 g simulated sweep.
- `locomotion_tuning.csv` preserves temporary controller sensitivity trials;
  those parameters were not saved into the cow model because higher tracking
  increased simulated acceleration substantially.
- `long_simulation/` contains the one-hour headless run. Its synchronized
  recording is compressed as `recording.jsonl.gz`; the raw high-volume Gazebo
  pose/IMU JSONL dumps are omitted. The normalized CSV and RESD are retained.
- `live_validation/` preserves the latest standing Gazebo integration run,
  including 523 IMU samples, 844 ear/tag pose samples, and the 7/11 `PARTIAL`
  per-run gate summary.

Each experiment's `summary.json` is generated by the fail-closed MVP3 report
command. `PARTIAL` means some digital integration requirements remain
`NOT_VALIDATED`; it is not a physical validation result.
